## Попробовать

Установи Python 3.10+ с Tkinter, затем выполни в этой папке:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe make_demo.py
.\.venv\Scripts\python.exe visual_review.py
```

Эти команды не требуют входа в Telegram или Google. Генератор создаст восемь вымышленных карточек зданий в `demo_data/sorted`. Демонстрационная рабочая папка исключена из Git.

В начале демо намеренно есть неразобранные группы. Проверка полноты может вернуть код 1: это означает «нужна ручная проверка», а не аварийное завершение.
